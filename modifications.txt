# SWEET MONEY — Frontend Redesign & UI Enhancement

You are working on my existing Personal Finance Tracker project. Your task is to transform its current frontend into a polished, modern, responsive and playful personal finance application called **Sweet Money**.

## 1. IMPORTANT: Analyze the existing project first

Before making any changes:

- Inspect the complete frontend structure.
- Identify the existing React components, pages, routes, services, hooks and styling system.
- Identify how the frontend communicates with the Django REST Framework backend.
- Inspect the existing authentication flow and API endpoints.
- Identify the existing charts, transaction management features and dashboard calculations.
- Identify the current dependencies and installed packages.

Do not assume that the project has a particular structure without inspecting it.

**Preserve all existing working features and backend integrations.**

Do not:
- Rebuild the backend.
- Change API endpoint names or response formats.
- Remove existing functionality.
- Replace real API data with mock data.
- Break authentication or transaction management.
- Rewrite the entire application unnecessarily.

If an important modification requires a backend change, explain why before implementing it.

After the analysis, provide a short implementation plan and proceed with the frontend improvements.

## 5. Glass-Click button design

Create a reusable button component named `GlassButton`.

This component must implement the Glass-Click interaction style.

Rest state:
- Frosted glass appearance.
- Semi-transparent background.
- Thin semi-transparent white border.
- Subtle backdrop blur.
- Rounded corners.
- Soft shadow where appropriate.

Pressed state:
- Slightly increase background opacity.
- Increase backdrop blur.
- Scale down slightly to simulate physical pressure.
- Make the border slightly more visible.

Suggested CSS behavior:

Rest:
- background: rgba(255, 255, 255, 0.45)
- border: 1px solid rgba(255, 255, 255, 0.75)
- backdrop-filter: blur(8px)
- transform: scale(1)

Pressed:
- background: rgba(255, 255, 255, 0.70)
- backdrop-filter: blur(14px)
- transform: scale(0.97)

Transition:
- 200ms ease

Additional requirements:
- Add a subtle highlight on the upper border.
- Support hover, focus-visible, disabled and loading states.
- Ensure keyboard accessibility.
- Respect prefers-reduced-motion.
- Provide a graceful fallback when backdrop-filter is unsupported.

Use this style consistently for buttons, including primary actions, while allowing the most important action to have a slightly stronger lavender tint.

Do not make buttons look like ordinary flat Bootstrap buttons.
